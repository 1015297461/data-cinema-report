## 1. 主题与色彩

浅色"纸面"主题（与深色版 v1 相比，本版为默认），禁止纯黑/纯白大面积背景。

| 变量 | 值 | 用途 |
|---|---|---|
| --bg | #f3f7fb | 页面底色（雾蓝，非纯白） |
| --bg2 | #eaf1f8 | 备用底 |
| --card | #ffffff | 卡片底（白卡+浅投影） |
| --line | #dde7f0 | 分隔线/边框 |
| --txt | #182a3f | 正文（深藏青，非纯黑） |
| --sub | #5c7a94 | 次级文字/轴文字 |
| --coral | #f97316 | 主强调（章节标签、渐变起点） |
| --cyan | #0e9db8 | 数据主色（当前期、正向大值） |
| --lime | #4c9d00 | 正向/涨 |
| --gold | #f59e0b | 洞察框、基准线、高亮 |
| --violet | #7c6cf0 | 辅助系列 |
| --rose | #e11d48 | 负向/跌 |

背景 = 三层径向渐变（coral 右上 8% / cyan 左中 7% / violet 底部 6%，透明度 ≤8%）+ `var(--bg)`。渐变代码在 template.html 中，直接复用勿重写。浅色版**无噪点纹理**。

配色语义规则（必须遵守）：
- 涨/改善 → lime 或 cyan；跌/恶化 → rose；基准线/均值线 → gold 虚线
- 多系列循环使用 PAL = [coral, cyan, lime, gold, violet, rose]
- 同一图表内对比期（如上一年）用 `rgba(154,167,196,.5)` 半透明灰，当前期用主题色
- 浅色底上的分隔线/网格线统一用 `rgba(24,42,63,.08)`；图表内文字统一 #5c7a94

## 2. 字体系统

| 类 | 字体 | 用途 |
|---|---|---|
| Display | Noto Serif SC 600/700/900（`.serif`） | 大标题、章节标题 |
| Body | Noto Sans SC 300/400/500/700 | 正文 |
| Mono | JetBrains Mono 400/600/800（`.mono` / `.kpi-num`） | KPI数字、标签代码、数据来源 |

Google Fonts 引入（仅 9 个字重，控制加载体积）：
`family=Noto+Serif+SC:wght@600;700;900&family=Noto+Sans+SC:wght@300;400;500;700&family=JetBrains+Mono:wght@400;600;800`

字体是唯一的外部 CDN 依赖（弱网下自动降级系统字体，可接受）；ECharts 已内联，无其他 CDN。

## 3. 页面结构

固定顺序，章节节奏不可变（**口径与公式统一收口文末，开篇不设独立 "00" 章**）：

1. **进度条** `#progress`（顶部 3px 三色渐变）
2. **HERO**：全屏（min-h-screen），含数据来源 chip（格式 `DATA SOURCE · 文件名 · 维度概览`）→ 主标题（第二行三色渐变字）→ 摘要（一段话说清数据范围+分析维度+推导目标）→ KPI 卡片网格（2×5，**静态 HTML**，含 pos/neg 同比着色）→ "SCROLL ↓ 共 n 章 · n 张图表 · 每图一句结论"提示；右上角超大装饰汉字（22vw，opacity .06）。**HERO 之后直接进 01 章，不再有「00 · METHODOLOGY」过渡章**
3. **01~N 分析章节**：`sec-tag`（mono 编号+英文标签）→ serif 章节标题（带一句观点式副题，如「市场规模：一年 486 万美元，仍在放量」）→ 一行副题 → 若干图表卡；**图表卡内标题按「章.序」编号**（如 2.1、3.2）
4. **结论/建议章节（可选，若有「值得做/机会清单/建议」类收尾）必须放在所有分析章节之后、APPENDIX 之前**，不要把结论卡组塞进中段。
5. **APPENDIX · METHODOLOGY**（必选，**全篇最后一块**）：divider 分隔线 → 单张卡，内含四段——
   - **口径说明**（`{{METHODOLOGY_TEXT}}`）：**精简为 3 行紧凑文本**（数据来源 / 时间口径 / 分组定义，青色小标题内联），**不再铺成左右两栏大卡**，也不再用 formula 虚线框单列公式
   - **公式与口径速查表**（`table.dt#tblF`，三列：指标 / 计算公式 / 数据来源字段）—— **这是公式的唯一出处**，正文与图表卡不再重复罗列
   - **口径注意事项脚注**（`{{APPENDIX_NOTES}}`）：含「重复累积」等多标签口径、同比基数下限等说明
   - **底部署名**（mono 居中，格式 `英文大写报告名 · Generated by QwenWork · Data: 文件名`）
- **可选：右上暗黑模式开关**——翻 `body.dark` 的 CSS 变量 + 用 `THEME`(light/dark) 调色板 `renderAll()` 重绘全部图表（图表色硬编码，光靠 CSS 翻不动；见 chart-recipes 13/14）。默认按 `prefers-color-scheme`。

## 4. 组件规范

- **图表卡** `.card p-6 reveal`：`<h3>` 编号小标题（如「2.1 一级大类搜索量同比」）→ `.chart`（高 420px；横向长榜/多类目涨跌榜可 480~560px，双栏并排用 `.chart-sm` 360px）→ `.insight` 一句话总结 → `.src` 数据来源行。一张卡内可放**多条 insight**（主结论 + 补充结论，后者 mt-2）
- **KPI 卡**（HERO 内，静态 HTML）：标签（sub 12px）+ `.kpi-num` 3xl~4xl 数字 + 底注（同比用 pos/neg 着色）；数字单位可用 `<span class="text-lg">` 缩小内联
- **insight 洞察框**：左侧 3px gold 竖线 + 金色 8% 底色（rgba(245,158,11,.08)），文字色 #6b4a12，句式固定为"一句话总结：…"；补充结论不加前缀直接续写
- **formula 公式框**（`.formula`，可选用）：mono 12px，cyan 7% 底 + cyan 虚线边框，文字色 #0b5a6b。**自 v2.2 起默认不再使用**——公式统一进文末附录速查表，此样式仅保留给个别需要就地强调公式的场景（如口径说明中的关键口径式）
- **src 来源行**：mono 11px，格式 `数据来源：{文件} · {字段/筛选条件}｜计算：{公式}`
- **数据表** `table.dt`：hover 行高亮（cyan 5%）、pos/neg 着色、长关键词截断加 `…`、ASIN/关键词等代码列用 `mono text-xs`
- **可排序明细表**：所有「核心指标明细」表默认支持点击表头排序（`fillTable(id, cols, rows, true)`），标题追加 `<span class="src">(点击任意表头排序)</span>`；表头右侧 ⇅ 占位、排序后变 ▲/▼ 并高亮 coral。**排序必须做数值解析**（$ % 千分位 K M 万 正负号），空值 `—` 沉底，纯文本走 localeCompare——否则 `$9.80` 会排在 `$19.32` 之后
- **明细表中文翻译并入英文名列**（`Wedding(婚礼)`、`Rose(玫瑰)`），**不单独开中文列**
- **多标签维度**（节日/品种/颜色）份额加总可超 100%，必须在文末 APPENDIX 的口径说明与 src 行写明「重复累积」口径
- **结论卡组**（可选，章末）：卡片顶部 2px 主题色边 + 序号标题（① ② ③…）+ 论据（含具体数字）+ 证据索引（`证据：X.X 图表`）
- **下钻联动面板**（可选）：图下方预置 `display:none` 的 chip 容器，点击图表某项后展示该项下的细分小类目 chips（见 chart-recipes.md 配方 11）

## 5. 图表规范（ECharts SVG，库已内联）

通过 `mk(id, opt)` 封装创建（见 template.html），自动注入字体、深色毛玻璃 tooltip（浅色报告仍用深色 tooltip 提高对比）。禁止使用 ECharts 默认样式。

统一约定：
- `grid:{left:10,right:X,top:Y,bottom:Z,containLabel:true}`；多类目轴 bottom 放宽到 90~110
- 轴文字颜色 `C.sub`（#5c7a94），轴线 `C.line`，分隔线 `rgba(24,42,63,.08)`
- 柱状图圆角 3~6px；条形榜条目右侧 mono 标签（10px，#5c7a94）
- 数值格式化用 fmtM / fmtK / pc / fnum；涨跌数字标签 9~10px mono
- 基准线：`markLine` gold 虚线 + `symbol:'none'`；排名条形可带 cyan 虚线均值线
- **轴名从简**：`yAxis.name` 只留极简单位（如「月销量(件)」）；「数值越小越好」「对数轴」「含长尾变体」等说明一律写进图表 h3 标题，避免长轴名与顶部刻度/图例重叠
- **多系列折线**：主线 `width:3 + symbolSize:6 + z:10`，其余 `width:1.8 + symbolSize:3`；必须配 `emphasis:{focus:'series'}` + **显式** `blur:{lineStyle:{opacity:.08}}`；**不要覆盖 tooltip.trigger**（保持默认 item，否则 axis 触发会绕过单线聚焦）；**主线只在位于图区底部时才加 areaStyle**（顶部线的面积块会覆盖全图、劫持悬停，表现为悬停哪里都聚焦同一条线）；配色数组长度须 ≥ 系列数
- **对数轴折线**（跨量级 >10 倍）：`yAxis.type:'log'` + 显式 min/max，**禁止 areaStyle**；标题点明「（对数轴）」；**不用双轴柱线做跨量级对比**（用户否定为不直观）
- **季节性图**：自然月 1~12 排列 + 单年度柱状 + 全年月均 gold 虚线，峰月 coral / 谷月 rose / 其余 cyan；**禁止**财年（8月~次年7月）双年对比
- 散点气泡：`symbolSize = sqrt(值/系数)` 映射，限定 10~52px；标签 `labelLayout:{hideOverlap:true}`，字号 9
- Treemap：色块用 LinearGradient（主题色 cc→55 透明度渐变），border 2px `#dbe7f2`
- X 轴类目过多（>20）时 label rotate 38~52°、字号 10
- 每个图表配置包在 IIFE 中 `(function(){ ... })();`，避免变量污染；需要绑定点击事件的用 `const c = mk(...); if(c){ c.on('click', ...) }`
- 大数据量散点可加 dataZoom inside（滚轮缩放/拖拽平移），并在图下加 mono 提示行「🖱 滚轮缩放 · 拖拽平移 · 双击还原视图」

## 6. 交互规范

- **滚动入场**：`.reveal` 默认 `opacity:0` + CSS transition（.6s cubic-bezier），进入视口时由 **IntersectionObserver**（threshold .08）加 `.in` 并 unobserve。**只淡入、不做 translateY 位移**——位移量一旦大于卡片间距（mb-6=24px），动画期间相邻模块外框会互相压叠。**不使用 GSAP**（零依赖，离线可用）
- **同 section 多卡片**：除末张外一律 `mb-6`，避免卡片粘连。**注意**：往章节末尾追加卡片时，原末卡会变成中间卡、必须补 `mb-6`（否则与新末卡贴合）；增删/重排卡片后跑一次卡片间距审计（见 pitfalls C2 / F2）
- **表格排序**：明细表表头可点，见组件规范「可排序明细表」
- **阅读进度**：顶部渐变进度条随 scroll 更新（原生 scroll 监听）
- **图表自适应**：window resize 时全部 chart.resize()
- **折线图交互基线**：多系列折线必须配置 emphasis:{focus:'series'} + 显式 blur{lineStyle:{opacity:.08}} + tooltip trigger:'axis'（配方见 chart-recipes.md 2b），保证悬停聚焦效果肉眼可见；双轴柱线组合图不加 focus
- **Hero 装饰字**：静态即可，无需 parallax
- 不要添加：轮播、抽屉、模态框等重交互；报告以滚动叙事为核心
- **验证方式**：默认只做静态自查（图表容器与 mk() 配置匹配、div/script 开闭配对、表格与 fillTable 匹配、D.xxx 键完整、node --check）；**截图验证须先征得用户同意**，仅在静态手段无法定位问题时才申请。建议把组装+自检写成常驻 `build_report.py`，每次改完重跑
- 图表点击下钻（可选）：`c.on('click', p => renderDrill(...))`，见 chart-recipes.md 配方 11

## 7. 内容规范（硬性要求）

每个图表卡必须三件套齐全：
1. **一句话总结**（insight 框）：一个可执行的结论句，含具体数字；重要图表可加第二条补充结论
2. **数据来源**（src 行）：明确到字段名或筛选条件，如"xlsx ·「202607月月搜索量」按分类聚合"
3. **计算公式**：凡有计算的必须写明，格式为自然语言，如"同比 = (Σ202607 − Σ202507) ÷ Σ202507 × 100%"；**每图公式就地写在 src 行，全部指标公式的完整清单统一收口到文末 APPENDIX · METHODOLOGY 速查表**（不设开篇 00 章），两处口径必须一致

正文引用数字必须与图表数据一致（生成后需回查校验：从聚合结果中重新取数核对 insight 中的每个数字）。

## 8. 离线与单文件要求

- **ECharts + ZRender 已内联**在 template.html 中（约 1MB，取自 echarts@5.5.0 官方构建），生成时直接以 template 为骨架，**禁止再引入任何 JS CDN**
- Tailwind 工具类已在模板 `<style>` 中本地化（仅覆盖报告用到的类），**禁止引入 Tailwind CDN**
- 唯一外部依赖：Google Fonts（可接受降级）；如需完全离线，可将字体子集内嵌（可选）
- 最终产物为单个 HTML 文件，双击即可打开，无需网络请求 JS 资源
